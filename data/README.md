# Data Directory

This directory contains the dataset at various stages of processing.

## Structure

```
data/
├── raw/            # Original downloaded dataset
├── interim/        # Development subsample and inspection outputs
├── processed/      # Clean, ready-to-use data (Phase 3+)
└── golden/         # Hand-labelled evaluation set (Phase 4+)
```

## Policies

### raw/

- Contains the original downloaded dataset files.
- **Never commit to Git.** Use `.gitignore` to exclude.
- Files are read-only; never modify originals.

### interim/

- Contains the development subsample and intermediate inspection outputs.
- Safe to commit (small files).
- Contains `development_sample.csv` and metadata files.

### processed/

- Contains clean, preprocessed datasets produced in later phases.
- Generated by pipeline scripts, not hand-edited.

### golden/

- Contains the hand-labelled evaluation set.
- Created in Phase 4.
- High quality; treated as ground truth.
